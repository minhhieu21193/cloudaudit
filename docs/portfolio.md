# Upwork portfolio entry

**Title** (60 characters)

AWS Cost & Security Audit CLI: Read-Only Review With Fixes

**Description**

A Go command-line tool I use for fixed-scope AWS reviews: with a read-only cross-account role, it runs 16 cost and security checks across regions and produces an HTML/PDF report with evidence, estimated monthly waste and a ready-to-run fix command for every finding. Read-only access is enforced in code and verified by tests, so clients can grant access with confidence. A built-in demo mode shows the full report without touching any AWS account.
